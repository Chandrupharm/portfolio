# Chandru Venkatesan — Pharmacy × Technology

A responsive, single-page portfolio bringing together Chandru's B.Pharm graduate background and the software, AI, and web projects featured in his linked portfolio.

## Run locally

This is a static website. Open `index.html` in a browser, or serve the project directory with any static file server.

## Personalize before publishing

- Confirm the project descriptions, skills, contact details, and any pharmacy-specific details before publishing. The project examples and software skills are based on the supplied portfolio link; the B.Pharm graduate description is based on the supplied CV filename.
- Social and external portfolio links are included as supplied.
